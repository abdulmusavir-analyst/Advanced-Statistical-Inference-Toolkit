# Advanced Statistical Inference and Hypothesis Testing Toolkit

## Project Overview
This project demonstrates statistical inference and hypothesis testing techniques using Python and a cleaned Superstore retail dataset.

The toolkit applies Maximum Likelihood Estimation (MLE), confidence interval estimation, and statistical hypothesis tests to analyze business data and support data-driven decision-making.

## Project Objectives
- Perform descriptive statistical analysis.
- Estimate distribution parameters using Maximum Likelihood Estimation.
- Calculate 95% confidence intervals.
- Apply independent two-sample hypothesis testing.
- Perform One-Way ANOVA and Kruskal-Wallis tests.
- Visualize statistical distributions and analytical findings.
- Interpret statistical results in a business context.

## How to Run the Project

1. Download or clone this repository.
2. Open Google Colab: https://colab.research.google.com/
3. Upload `Advanced_Statistical_Inference_Toolkit.ipynb`.
4. Run the notebook cells in sequence.
5. Upload `superstore_cleaned_for_analytics.csv` when prompted.
6. Review the generated statistical results and visualizations.

Statistical conclusions depend on the dataset, assumptions and significance level used. Results should be interpreted in context. The notebook should be executed to generate and verify the actual numerical findings.
